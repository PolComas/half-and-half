Ruta de referència basada en codi real; no és el registre d’un recorregut interactiu fet per l’usuari.

  1. server/generationService.ts · GenerationService.run

    La funció SQL hh_claim_attempt concedeix l’enviament a un sol executor. L’original es desa en privat abans de preparar la base; una resposta incerta no provoca un reintent de pagament automàtic.

  2. server/openaiImages.ts · imagePrompt i generateImage

    imagePrompt demana un sol subjecte híbrid. generateImage fa POST /v1/images/generations amb Authorization: Bearer …, model fix, n: 1, qualitat baixa i mida fixa. La clau arriba d’una variable del servidor; el navegador no la rep.

    n: 1 fixa el nombre d’imatges retornades. La fusió dels dos conceptes es defineix al prompt i es comprova mirant la imatge. La resposta es valida i data[0].b64_json es converteix en bytes; usage permet registrar l’ús si el proveïdor el retorna.

  3. server/imageService.ts · prepareImage

    Esquerra: columnes 0–511. Dreta: 512–1023. Es conserva una base immutable. La ruta GET /api/room/base comprova la sessió i serveix només la meitat assignada.

Les peces que fan la ronda

React: mostra sala i estat, eines de pintura, espera i revelació.

Node + Express: comprova el participant, coordina generació i finalització, i serveix les imatges autoritzades.

IndexedDB + Web Locks: desen colors al navegador i permeten una sola pestanya editora per meitat. Un magatzem separat conserva tres PNG ja revelats en aquest navegador.

Supabase: conserva sala, intents i finals; les imatges són en Storage privat, accessibles a través del servidor.

El primer final desat congela només aquella meitat. El segon final compatible permet compondre blanc + colors esquerres + colors drets + contorns i publicar una única referència de resultat.

Una pràctica per reutilitzar

Defineix què s’ha de poder observar i comprova una mostra real. «Combinar les idees» produïa dos personatges dins de la mateixa imatge. La concreció «un sol subjecte físicament híbrid» va permetre corregir el prompt i avaluar una generació nova.

La prova del contracte de petició a tests/domain/openai.test.ts comprova paràmetres i absència de reintents ocults. La revisió visual i les proves reals registrades a devpost/verification.md aporten evidència del resultat. En un altre projecte amb IA, prepara totes dues comprovacions des del primer increment.

Tornar a executar

A l’arrel del projecte, amb Node 24, dependències i .env local configurats:

npm run dev

Obre http://localhost:5173. Fes servir dos perfils o navegadors diferents per ocupar les dues places; dues pestanyes del mateix perfil comparteixen participant. Ctrl+C atura els processos iniciats per l’ordre.

Consulta el README per instal·lació i comprovacions. Tornar a una sala existent no requereix generar una altra imatge; les rondes noves i els reintents autoritzats consumeixen crèdits i quota.
